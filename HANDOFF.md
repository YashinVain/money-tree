# HANDOFF — состояние проекта «Денежное дерево»

Файл для того, кто продолжит работу (человек или ИИ). Читать вместе с [README.md](README.md)
и [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Коротко

- **Что это:** уютный кликер для Яндекс Игр. Тап по дереву → монетки; дерево растёт через
  8 стадий; зверята дают пассивный доход; радуга → «Радужный дождь» x2; золотые бабочки;
  волшебные цветы; престиж «Новый сад» за золотые семена; подарок дня, задания, достижения,
  копилка (оффлайн-доход), бонусы за рекламу.
- **Аудитория:** дети и взрослые 30+, короткие заходы по несколько минут, важно возвращаться.
- **Технологии:** чистый JavaScript без сборщиков и библиотек, обычные `<script>` в
  `index.html`, общее пространство имён `window.R`. Вся графика рисуется кодом на Canvas,
  весь звук — синтез Web Audio. Внешних ресурсов нет.
- **Репозиторий:** https://github.com/YashinVain/money-tree — работа в ветке `dev`,
  `main` — только проверенные версии с тегами `v1.0.0` и т.д.
  Тег `v0.9-resonance` — старая версия «Резонанс» на Phaser, от которой отказались.

## Как запустить и проверить

```bash
node tools/test.js                          # автотесты логики (должно быть 0 упало)
node tools/sim.js sessions                  # темп игры короткими заходами
node tools/build.js                         # архив dist/money-tree.zip для Яндекса
npx http-server -p 8934 -c-1                # локальный сервер (или любой другой)
node tools/shot.js tools/scenarios/smoke.json   # снимки экранов в Edge без окна
```

Сценарии `tools/scenarios/*.json`: `smoke` (основной проход), `seed` (все стадии),
`modals` (окна), `anim` (кадры анимации), `perf` (FPS при замедленном CPU и звук),
`dist` (собранная версия), `yandex` (через `sdk-dev-proxy`, реклама и облако),
`promo` (иконка и обложки в `docs/promo`).

Отладка в консоли браузера: `R.main.debug.coins(1e6)`, `R.main.debug.level(60)`,
`R.main.debug.reset()`, состояние — `R.game.S`.

## Что сделано и проверено (16.10.2026) — версия 1.0.0

- Игра полностью играбельна от семечка до Древа Мира и нового сада, на русском и английском.
- Раскладки: телефон вертикально и боком, планшет, компьютер. Проверены снимками 320×568, 360×640,
  390×844, 568×320, 740×360, 768×1024, 1280×720, 1920×1080 (сценарии `sizes`, `lowmodal`, `r2check`).
- SDK Яндекса проверен через `sdk-dev-proxy`: init, getPlayer, облако getData/setData,
  LoadingAPI.ready, GameplayAPI start/stop, game_api_pause/resume, rewarded (награда только
  после закрытия), полноэкранная реклама.
- 38 автотестов логики проходят. FPS в полностью заросшем саду: 132 обычно, 100 при CPU, замедленном
  в 4 раза, 86 — то же с частыми тапами, ~73 при замедлении в 6 раз с открытием панели
  (сценарии `perf`, `perf6`, `perf7`). Зверята рисуются в свои
  холсты 20 раз в секунду, цветы — готовыми картинками, на медленных устройствах плотность пикселей
  снижается автоматически, портреты для панелей готовятся заранее в простое.
- Иконка 512×512 и обложки 800×470 (RU/EN) в `docs/promo`.

## Цикл проверки

По просьбе автора работа идёт кругами: независимые агенты-критики (код и требования Яндекса;
геймдизайн и UX) проверяют игру с нуля → исправления → новый круг. Раунд 1 исправлен
в коммите `57440c8` (блокер с окнами на низких экранах, копилка, двойные награды,
поддельная реклама, облако, производительность, тексты, геймдизайн). Раунд 2 — в `522830a`
(телефон боком 568×320, кнопки над открытой панелью, корзинка и тапы по зверятам в саду,
престиж с 75 уровня, полноэкранная реклама только в спокойные паузы, скорость на слабых телефонах).
Раунд 4 (финальный, блокеров и серьёзных ошибок нет) — честные награды в первые минуты,
предложение рекламы не на кроне и не под пальцем, понятное подтверждение нового сада,
компактная панель на телефоне боком, формы слов в достижениях, защита дат и прототипа
в сохранениях. Раунд 3 — в `5253dd0` (битые сохранения, гостевой сад при входе, таймауты SDK, одна вкладка,
сворачиваемая боковая панель, честная реклама для детей, спокойное начало, разные стадии дерева,
мягкая серия подарков, темп «Цветущего дерева», живой таймер заданий).

Правила рекламы (не ломать при правках): rewarded — только по кнопке игрока, награда только
после закрытия ролика; полноэкранная — только после закрытия окна «Дерево выросло» (`A.stageTake` в main.js) и если поверх нет окон,
не чаще `interstitialGap`, не раньше 5 минут игры, таймер сбрасывается после rewarded.
В окнах наград «Забрать» — первая и главная кнопка, «за рекламу» — вторая (`ad-alt`).
Предложение x3 после бабочки — вверху сада и нажимается только через 1 секунду.
