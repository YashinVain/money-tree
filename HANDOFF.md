# HANDOFF — состояние проекта «Денежное дерево»

Файл для того, кто продолжит работу (человек или ИИ). Читать вместе с [README.md](README.md)
и [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Коротко

- **Что это:** уютный кликер для Яндекс Игр. Тап по дереву → монетки; дерево растёт через
  8 стадий; зверята дают пассивный доход; радуга → «Радужный час» x2; золотые бабочки;
  волшебные цветы; престиж «Новый сад» за золотые семена; подарок дня, задания, достижения,
  копилка (оффлайн-доход), бонусы за рекламу.
- **Аудитория:** дети и взрослые 30+, короткие заходы по несколько минут, важно возвращаться.
- **Технологии:** чистый JavaScript без сборщиков и библиотек, обычные `<script>` в
  `index.html`, общее пространство имён `window.R`. Вся графика рисуется кодом на Canvas,
  весь звук — синтез Web Audio. Внешних ресурсов нет.
- **Репозиторий:** https://github.com/YashinVain/money-tree — работа в ветке `dev`,
  `main` — только проверенные версии с тегами `v1.0.0` и т.д.
  Тег `v0.9-resonance` — старая версия «Резонанс» на Phaser, от которой отказались.

## Как запустить и проверить

```bash
node tools/test.js                          # автотесты логики (должно быть 0 упало)
node tools/sim.js sessions                  # темп игры короткими заходами
node tools/build.js                         # архив dist/money-tree.zip для Яндекса
npx http-server -p 8934 -c-1                # локальный сервер (или любой другой)
node tools/shot.js tools/scenarios/smoke.json   # снимки экранов в Edge без окна
```

Сценарии `tools/scenarios/*.json`: `smoke` (основной проход), `seed` (все стадии),
`modals` (окна), `anim` (кадры анимации), `perf` (FPS при замедленном CPU и звук),
`dist` (собранная версия), `yandex` (через `sdk-dev-proxy`, реклама и облако),
`promo` (иконка и обложки в `docs/promo`).

Отладка в консоли браузера: `R.main.debug.coins(1e6)`, `R.main.debug.level(60)`,
`R.main.debug.reset()`, состояние — `R.game.S`.

| Вид дерева | `js/view/tree.js` |

## Что сделано и проверено (14.10.2026)

- Игра полностью играбельна от семечка до Древа Мира и нового сада, на русском и английском.
- Раскладки: телефон (вертикально) и компьютер (горизонтально), проверены снимками 390×844 и 1280×720.
- SDK Яндекса проверен через `sdk-dev-proxy`: init, getPlayer, облако getData/setData,
  LoadingAPI.ready, GameplayAPI start/stop, game_api_pause/resume, rewarded (награда только
  после закрытия), полноэкранная реклама.
- 27 автотестов логики проходят; FPS около 55 при CPU, замедленном в 4 раза, в полностью заросшем саду.
- Иконка 512×512 и обложки 800×470 (RU/EN) в `docs/promo`.

## Цикл проверки
