# Публикация «Денежного дерева» на Яндекс Играх

Пошаговая инструкция: от сборки архива до отправки на модерацию.
Все тексты для черновика ниже уже готовы — их можно просто копировать.

---

## 1. Собрать архив

```bash
node tools/test.js
node tools/build.js
```

Первая команда проверяет логику игры (должно быть «0 упало»), вторая создаёт
`dist/money-tree.zip` (~170 КБ): внутри `index.html` в корне, `game.js`, `css/style.css`
и шрифт Nunito в `fonts/` (с лицензией OFL — свободный шрифт, его можно распространять с игрой).
Имена без пробелов и кириллицы — как требует пункт 1.22.

## 2. Проверить с SDK Яндекса у себя на компьютере (по желанию)

```bash
sdk-dev-proxy -p dist/money-tree --dev-mode=true
```

Откроется адрес `https://localhost:8080` (браузер предупредит о сертификате — это нормально,
нажми «Всё равно перейти»). Реклама там показывается заглушкой с надписью «Rewarded Video».

## 3. Черновик в консоли

1. Зайди на https://games.yandex.ru/console → «Добавить приложение».
2. Заполни поля текстами из раздела 4, загрузи картинки из раздела 5.
3. **Архив:** загрузи `dist/money-tree.zip`.
4. **Платформы:** компьютеры и мобильные. **Ориентация:** любая (игра сама подстраивается).
5. **Облачные сохранения:** включи опцию (пункт 1.11), игра их использует.
6. **Sticky-баннер:** можно включить в консоли — интерфейс игры его не перекрывает.
7. **Таблица лидеров (по желанию):** создай лидерборд с техническим названием `moneytree`
   (тип — числа, по убыванию). Игра записывает туда количество золотых семян,
   кнопка «Лучшие садовники» появится в настройках сама.
8. Открой черновик со ссылкой вида `...?draft=true&debug-mode=16` и проверь
   рекламу, сохранения и звук при сворачивании вкладки.
9. Нажми «Отправить на модерацию».

## 4. Тексты для черновика

### Русский

**Название:** Денежное дерево

**Короткое описание (до ~100 символов):**
Вырасти волшебное денежное дерево вместе со зверятами!

**Об игре:**
Посади маленькое семечко — и вырасти из него настоящее волшебное дерево! Тапай по дереву,
и с его веток посыплются золотые монетки. Дерево растёт у тебя на глазах: из семечка
появляется росток, потом саженец, пышное цветущее дерево, яблоня с румяными яблоками,
светящееся волшебное дерево и, наконец, огромное Древо Мира с домиком на ветках.

Зови в сад зверят: пчёлку, ёжика, белочку, кролика, сову и маленького дракончика.
Они живут в саду и сами приносят монетки — даже когда ты не в игре.
Наполняй радугу тапами и включай радужный дождь, лови золотых бабочек с сюрпризами,
собирай коллекцию волшебных цветов и сажай новые сады, которые растут ещё быстрее.

Спокойная и добрая игра на пару минут, к которой приятно возвращаться каждый день:
подарок дня, задания, достижения и копилка, которая наполняется, пока тебя нет.

**Как играть:**
Тапай по дереву, чтобы собирать монетки. В разделе «Дерево» выращивай его — каждый уровень
даёт больше монеток за тап, а новая стадия меняет вид дерева. В разделе «Зверята» зови
помощников: они приносят монетки каждую секунду. Когда радуга над деревом наполнится, нажми
«Радуга!» — монеток станет вдвое больше. Лови золотую бабочку, если она пролетает мимо.
Когда вырастет Яблоня, можно посадить новый сад и получить золотые семена для вечных бонусов.
На компьютере: пробел — тап по дереву, R или Enter — радуга.

**Теги/ключевые слова:** кликер, idle, дерево, сад, монеты, зверята, животные, для детей,
спокойная, расслабляющая, казуальная

**Категории:** Казуальные, Детские (по желанию — Экономические)

**Возраст:** 0+

**Name:** Money Tree

**Short description:** Grow a magic money tree with cute animal friends!

**About the game:**
Plant a tiny seed and grow it into a real magic tree! Tap the tree and golden coins fall

an apple tree, a glowing magic tree and finally the giant World Tree with a little house

Invite animal friends to your garden: a bee, a hedgehog, a squirrel, a bunny, an owl

A calm and kind game for a couple of minutes that is fun to come back to every day:

**How to play:**
Tap the tree to collect coins. In “Tree”, grow it — each level gives more coins per tap,
and a new stage changes how the tree looks. In “Animals”, invite helpers: they bring coins
every second. When the rainbow above the tree is full, press “Rainbow!” for double coins.
Catch the golden butterfly when it flies by. When the Apple tree grows, you can plant a new
garden and get golden seeds for permanent bonuses.
On a computer: Space — tap the tree, R or Enter — rainbow.

## 6. Что проверяют модераторы (и как это сделано)

| Требование | Как сделано |
|---|---|
| 1.3 звук выключается при потере фокуса | `audio.pause()` на `blur`, `visibilitychange`, во время рекламы |
| 1.9 прогресс сохраняется сразу | localStorage после каждого действия + облако (`player.setData`) |
| 1.10 нет обрезанных/наложенных элементов | две раскладки (телефон/компьютер), проверено на 320–1920 px |
| 1.19 SDK: `LoadingAPI.ready`, `GameplayAPI` | ready — когда можно играть; start/stop — окна, реклама, сворачивание |
| 4.4 реклама в логических паузах | полноэкранная — после нового сада, после копилки и когда игрок сам закрыл «Цели»/«Настройки»; не чаще раза в 3 мин и не в первые 5 минут игры |
| 1.16 реклама не имитируется | тестовое окно рекламы появляется только на компьютере разработчика (localhost/файл); на сайте без SDK кнопки рекламы скрыты |
| 4.5 награда за рекламу — бонус, не обязаловка | все бонусы можно не смотреть, игра проходится без рекламы |
| 2.14 автоопределение языка | `ysdk.environment.i18n.lang`, ручной выбор в настройках |
| 1.6.1.8 долгое нажатие | контекстное меню и выделение текста отключены |
| 8.4.2 нет внешних ресурсов | шрифты системные, графика и звук создаются кодом |

## 7. Обновления после выпуска

- Меняй `R.VERSION` в `js/main.js`, собирай заново, загружай новый архив в тот же черновик.
- Сохранения игроков не сломаются: при загрузке новые поля получают значения по умолчанию
  (`js/game/save.js`, функция `apply`). Не переименовывай существующие поля состояния.
- Идеи для обновлений: сезонные события (осенний сад, новогодняя ёлка), новые зверята,
  ещё стадии после Древа Мира, украшения для сада.
