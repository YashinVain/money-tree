# Денежное дерево 🌳🪙

Уютный кликер для **Яндекс Игр**. Тапай по волшебному дереву — из него сыплются монетки.
Расти дерево от семечка до Древа Мира, зови зверят-помощников, лови золотых бабочек
и сажай новые сады, которые растут ещё быстрее.

Игра рассчитана на короткие спокойные заходы на несколько минут (дети и взрослые, которые
зашли расслабиться). Пока игрока нет, зверята копят монетки в копилку, поэтому
возвращаться всегда приятно.

> Раньше проект назывался «Резонанс» (кликер на Phaser про резонатор).
> Старая версия сохранена в истории git: коммит `28a54f7`.

## Что есть в игре

| Механика | Как работает |
|---|---|
| **Дерево** | Тап даёт монетки. 8 стадий по 15 уровней: Семечко → Росток → Саженец → Деревце → Цветущее → Яблоня → Волшебное → Древо Мира. Каждая стадия выглядит по-новому и даёт своё умение. |
| **Радуга** | Тапы наполняют радугу над деревом. Полная радуга → кнопка «Радуга!» → **Радужный дождь**: все монетки x2 (x3 с Подсолнухом). |
| **Золотой тап** | С самого начала 3% тапов — золотые (монетки x5); Роза делает их чаще и щедрее. |
| **Зверята** | Пчёлка, Ёжик, Белочка, Кролик, Сова, Дракончик. Приносят монетки каждую секунду, гуляют по саду и радуются, если по ним тапнуть. На 10/25/50/… уровнях — вехи x2. |
| **Волшебные цветы** | 8 цветов, по одному за каждую выращенную стадию. Растут в саду и дают постоянные бонусы. |
| **Золотая бабочка** | Иногда пролетает по экрану. Поймай тапом — внутри мешочек монет, шквал тапов x7 или готовая радуга. |
| **Новый сад** (престиж) | С 75 уровня (Цветущее дерево) можно начать заново и получить **золотые семена**. На них покупаются вечные бонусы: Лейка, Удобрение, Грядка, Сачок, Дневник садовника, Копилка побольше. Лучший зверёк переезжает в новый сад с половиной уровней (с Дневником — со всеми). |
| **Копилка** | Пока игрока нет, зверята работают (30% скорости, до 4 часов, бонусами — больше). |
| **Подарки** | Подарок дня с растущей серией (сам открывается при первом заходе за день, на 7-й день — золотые семена), бесплатная корзинка раз в 3 часа (стоит прямо в саду — тапни по ней), бонусы за рекламу (x2 монеток, мешок монет, радужный дождь на минуту), подарок за каждую новую стадию дерева. |
| **Украшения сада** | Грибочки, заборчик, скворечник, прудик, мельница, домик, фонтан, замок… Появляются по мере роста дерева и остаются навсегда, даже после нового сада. |
| **Цели** | 3 ежедневных задания и достижения (каждое +2% к монеткам навсегда). |
| **Реклама** | Только по желанию игрока (x2 монеток, мешок, дождь, удвоение подарков). Полноэкранная — не чаще раза в 3 минуты, не в первые 5 минут игры, только в спокойные паузы и никогда сразу после рекламы за награду. |

Языки: русский и английский (определяются автоматически через SDK, можно сменить в настройках).

## Как запустить

**Самый простой способ** — открыть `index.html` двойным кликом. Игра работает и без сервера,
в «тестовом режиме»: реклама имитируется коротким окном с надписью «Тестовая реклама».

**Через локальный сервер** (так ближе к Яндексу):

```bash
node tools/serve.js
```

и открыть http://127.0.0.1:8934

**На телефоне** (телефон и компьютер в одной сети Wi-Fi):

```bash
node tools/serve.js 8935 --lan
```

Сервер напечатает адрес вида `http://192.168.x.x:8935/` — его нужно открыть в браузере телефона.
Если Windows спросит про доступ node.js к сети — разрешить для частных сетей.

**Послушать звуки** — открыть `tools/sounds.html`: каждый звук игры по кнопке и музыка всех стадий.

**С настоящим SDK Яндекса** (нужен пакет `@yandex-games/sdk-dev-proxy`):

```bash
sdk-dev-proxy -p . --dev-mode=true
```

```
│   ├── core/             — базовые модули, не зависят от правил игры
│   │   ├── util.js       — математика, цвета, форматирование чисел, шина событий R.on/R.emit
│   │   ├── i18n.js       — все тексты на русском и английском, функция R.t()
│   │   ├── sdk.js        — обёртка SDK Яндекс Игр: реклама, облачные сохранения, пауза
│   │   └── audio.js      — звук и музыка, синтезируются кодом (без аудиофайлов)
│   ├── game/             — правила игры (без отрисовки, можно запускать в node)
│   │   ├── config.js     — ВСЕ числа баланса: цены, доход, длительности
│   │   ├── game.js       — состояние и действия: тап, покупки, радуга, новый сад
│   │   ├── meta.js       — достижения, ежедневные задания, подарок дня
│   │   └── save.js       — сохранение в localStorage и облако Яндекса
│   ├── view/             — графика (Canvas), всё нарисовано кодом
│   │   ├── paint.js      — «кисточки»: монетка, семечко, бабочка, облака, радуга
│   │   ├── tree.js       — дерево по стадиям
│   │   ├── critters.js   — зверята
│   │   ├── flowers.js    — волшебные цветы
│   │   └── scene.js      — сад целиком: небо, холмы, дерево, частицы, анимации
│   ├── ui/               — интерфейс поверх сада (HTML)
│   └── main.js           — запуск игры и главный цикл
├── tools/
│   ├── sim.js            — симулятор баланса (виртуальный игрок)
│   ├── test.js           — автотесты логики
│   ├── build.js          — сборка ZIP-архива для Яндекс Игр
│   ├── build-web.js      — тестовая сборка для проверки на телефоне по ссылке (без SDK)
│   ├── serve.js          — локальный сервер (с --lan — для проверки на телефоне)
│   ├── sounds.html       — пульт: послушать каждый звук и музыку
│   ├── shot.js           — снимки экранов и автопроверки в Edge без окна
│   ├── record.js         — видео геймплея для Яндекса (MP4, H.264): record-player.js + mp4.js
│   └── strip.js          — убирает комментарии из кода сборки

```

Модули общаются через события: например, `game.js` сообщает `R.emit('stage', ...)`,
когда дерево выросло, а звук, интерфейс и достижения сами на это реагируют.

## Баланс

Все числа лежат в [`js/game/config.js`](js/game/config.js). После изменений проверь темп:

```bash
node tools/sim.js            # непрерывная игра: на какой минуте открываются стадии
node tools/sim.js sessions   # короткие заходы по 4 минуты с перерывами по 4 часа
```

Текущий темп (заходы по 4 минуты, 3 тапа в секунду): 1-й заход — дерево дорастает до Саженца,
2-й — Деревце, 3-й — Цветущее дерево, 4-й — Яблоня и первый новый сад (при 1,5 тапа в секунду — 5-й).
Древо Мира — через несколько дней игры.

## Требования Яндекс Игр, которые учтены

- SDK подключается через `/sdk.js`, вызываются `LoadingAPI.ready()`, `GameplayAPI.start/stop`.
- Звук выключается, когда вкладка неактивна или идёт реклама.
- Прогресс сохраняется сразу (localStorage) и в облако (`player.setData`, не чаще лимита).
- Реклама — только через SDK: полноэкранная в паузах (не чаще раза в 3 минуты), за награду — по кнопке.
- Нет контекстного меню и выделения текста при долгом нажатии, нет прокрутки страницы.
- Работает и в портретной (телефон), и в альбомной (компьютер) ориентации.
- Никаких внешних ресурсов: шрифты системные, вся графика и звук генерируются кодом.
